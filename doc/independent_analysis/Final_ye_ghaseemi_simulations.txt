cannot support with two levels.

16.2  A NEW TOOL: scripts/retune_aperture_law.py

Table 2's flow is the cubic law, so Q is a direct readout of a_h, and every
finished run exports hydraulic_aperture_um_pp AND normal_stress_aperture_um_pp.
That means the stress term can be swapped for a candidate law EXACTLY while every
other contribution is carried over unchanged:

    a_h_new = a_h_model - stress_aperture_old + stress_aperture_new
    Q_new   = Q_model * (a_h_new / a_h_model)^3

The tool fits both implemented laws (linear compliance, BB power law) against
Table 2's flow, jointly with aperture_scale on the mode-I specimens where the
mechanical term is recoverable in closed form. Caveat carried in the docstring:
aperture feeds back into pressure diffusion and hence sigma'_n, so it RANKS
candidates, it does not forecast scores.

16.4  THE SOURCE CHANGE: STRESS-DEPENDENT TANGENTIAL STIFFNESS
--------------------------------------------------------------------------------

THE GAP. Every specimen creeps in shear before its event and this model does not:

  SW-T1  Table 2 d_s  0.000 0.000 0.001 0.002 0.008 mm   model 0.000 0.000 0.000 0.000 0.001
  SW-T2  Table 2 d_s  0.000 0.001 0.003 0.007 0.015 mm   model 0.000 0.000 0.000 0.000 0.003

and it happens while tau is FALLING (SW-T2: 74.87 -> 73.40 MPa). What changes is
sigma'_n, 66.7 -> 57.9 MPa.

WHY NO VALUE OF penalty_tangent FIXES IT. With a constant tangential stiffness the
elastic shear jump is tau/k_t, and tau is flat, so the modelled d_s is flat too --
0.02 um of change across stages 1-5 at k_t = 1e13, and proportionally flat at any
other constant. Softening the penalty moves the DATUM, which stage-1 referencing
removes. This is structural. It also settles the sec.14 penalty_tangent question
in a way sec.15 did not: the parameter is not innocent, but the fix is not a new
value of it.

WHAT THE LITERATURE SAYS. Barton-Bandis: k_s = (100/L)*sigma'_n*tan(phi_peak).
For these 50 mm specimens at sigma'_n ~ 66 MPa and phi_peak ~ 46 deg that is
~1.4e12 Pa/m -- roughly 7x SOFTER than the 1e13 this campaign has used, which was
chosen as a numerical penalty and never checked against it.

THE CHANGE (opt-in, default false = byte-identical to every previous deck), in
ADOrcaBartonBandisContactTractionFastAD:

    k_t(sigma'_n) = max(min_tangential_stiffness_fraction, (sigma'_n/sigma_ref)^m)
                    * penalty_tangent

evaluated on the START-OF-STEP effective normal stress, so k_t is a constant
inside the step and every return-map expression keeps its algebra; only the
Jacobian's dependence of k_t on jump(0) is dropped (the value is exact).
penalty_tangent becomes the stiffness AT sigma_ref. New parameters:
use_stress_dependent_tangential_stiffness, tangential_stiffness_reference_stress,
tangential_stiffness_exponent, min_tangential_stiffness_fraction. New exported
property: bb_tangential_stiffness. The one-line override in
ADOrcaBartonBandisContactTractionFastADHardening::computeReturnMappingDerivative
is repointed with it.

VERIFIED LOCALLY (10 ranks, this workstation):

    differential_stress_reaction_mpa_pp and hydraulic_aperture_um_pp identical to

Sec.15.4 read stage 4 as delayed onset. That is wrong and is withdrawn here.
limit_tau_pp at stage 4 is 12.291 MPa against a model tau of 12.121 -- the joint

0.1968; residual 22.92*tan(6.50 deg) = 2.611 MPa; required peak
