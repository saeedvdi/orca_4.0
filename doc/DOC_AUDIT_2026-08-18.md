# Audit of `orca_czm_theory.md` and `paper_draft_ye_ghassemi_validation.md`

2026-08-18. Branch `orca_v6`, repo `orca_4.0`.

**Scope.** Every formulation in both documents checked against the current source
(`src/InterfaceMaterial/`, `include/utils/OrcaNormalClosure.h`, `src/kernels/`) and against
the parameter values actually set in the four validated production decks
(`93_01`, `93_03`, `93_05`, `93_07`). Results and discussion claims checked against the
current scorecard and against the findings of 2026-08-17/18.

**Provenance of the staleness.** Both documents were last written in commit `2076495`
(2026-08-16 19:27). Eight commits have landed since — `cd4f0bc`, `bcc46bb`, `a23b61b`,
`d48aaa8`, `5469b97`, `e2aae11`, `eee7e74`, `da5c67f`, `60e5edf`, `3791975` — including one
new constitutive material and the entire Table-2 scoring campaign. Neither document has
been touched since.

**Verdict.** The mathematical structure is sound and the exposition is good. But there are
**six places where the stated formulation does not match the code that produced the
results**, and one of them — the state-dependent fault-pressure coefficient — carries a
whole discussion subsection describing a feature that is switched off in every validated
run. These are correctness defects, not polish.

---

## Part A — Formulation errors: the docs describe something the code does not do

### A1. The state-dependent α_f is disabled in every production deck (**most serious**)

**Affects:** paper §3.6.1 (boxed equation), §6.2 (entire subsection, ~500 words),
§6.6 limitation 7, Table 4 row "Fracture pressure–area reference stress".

The manuscript's §3.6.1 presents

$$\alpha_f(\sigma'_n) = \frac{\sigma_0}{\sigma_0+\sigma'_n}$$

as the adopted formulation, and §6.2 builds an argument on it: that it is a positive
feedback whose sign is a prediction, and that it resolved a convergence failure without a
fitted degree of freedom.

The switch is `use_state_dependent_fault_pressure_coefficient`, declared at
`src/InterfaceMaterial/ADOrcaBartonBandisContactTractionFastAD.C:264`, **default `false`**.
No 93-series or 94-series deck sets it. `grep` across all eight returns nothing.

What the validated decks actually use is a flat constant:

| specimen | `fault_pressure_coefficient` |
|---|---|
| SW-T1 | 1.0 |
| SW-T2 | 1.0 |
| SW-S3 | 0.87 |
| SW-S4 | 0.86 |

Two of the four apply no attenuation at all. So §6.2's central claim — that the coupling
steepens as the joint approaches failure, which a constant-α_f model cannot produce — is
a description of a code path the results did not exercise.

A second problem sits inside §6.2 even if the feature were enabled: it says the constant
formulation "failed to converge through the slip/arrest transient on SW-S4 **under
Mohr–Coulomb**". That was an MC deck. It is not evidence about the Barton–Bandis runs the
paper reports.

**Fix.** Either (i) cut §3.6.1, §6.2, limitation 7 and the Table 4 row, and state plainly
that α_f is a fitted constant per specimen — 1.0 on the tensile pair, 0.86–0.87 on the saw
cuts; or (ii) enable the feature and rerun. Option (i) is honest and costs nothing;
option (ii) is a new calibration campaign. Note that with α = 0.6 in the matrix, α_f is
already partly redundant with the Biot coefficient — see the standing note on the
inconsistent poroelastic constants.

### A2. The normal-closure equation omits the stress exponent

**Affects:** paper §3.4; theory `eq:powerlawclosure` cross-references.

Paper §3.4 displays

$$v(\sigma'_n) = \frac{\sigma'_n}{K_{ni} + \sigma'_n/v_m}$$

and calls it "a Bandis-type hyperbolic closure with a stress exponent". The displayed
equation has no exponent in it. The source
(`include/utils/OrcaNormalClosure.h:44`, and the parameter doc at
`ADOrcaBartonBandisContactTractionFastAD.C:101`) implements

$$\sigma_n = K_{ni} v_m \left[\frac{v}{v_m - v}\right]^{1/p}, \qquad
  v = \frac{v_m \sigma_n^{\,p}}{\sigma_0^{\,p} + \sigma_n^{\,p}}, \qquad \sigma_0 = K_{ni} v_m .$$

The paper's form is the $p=1$ special case. The decks use $p = 4.0$ (SW-T1), $4.0$ (SW-T2),
$4.0$ (SW-S3), $2.0$ (SW-S4). None of them is 1.

This is not cosmetic: the tangent normal stiffness scales like $\sigma_n^{p+1}$ at
$\sigma_n \gg \sigma_0$, which is the whole reason $p$ was introduced — it reproduces the
~3–4× unload stiffening. At $p=1$ that stiffening does not exist.

**Also:** SW-T1 sets `use_nonlinear_normal_closure = false` in its aperture material, so its
*hydraulic* stress-aperture term is linear while the other three are power-law. The docs
describe one law for all four.

### A3. The hydraulic-aperture law is incomplete in both docs, and its headline claim is false for half the specimens

**Affects:** paper §3.6 and §3.5.4; theory `eq:aperture` and the "Remark: What *not* to do".

Both documents state a three-term law. The paper:

$$a_h = a_{h0} + \chi\langle g_n\rangle_+ - a_{\rm gouge}(s)$$

The theory manual drops $\chi$ entirely, writing $a_h = a_{h0} + \langle g_n\rangle_+ -
a_{\rm gouge}$. That implies $\chi = 1$, where the decks run $\chi =$ 0.016, 0.0165, 0.001,
0.001 — a factor of 60 to 1000 off.

The source (`ADOrcaRoughnessDamageFracturePermeability.C:453`) assembles six terms:

```
a_h = a_h0 + stress_aperture(σ'_n)
           + aperture_scale · a_m
           + dilation_scale · Σdilation · retention_factor
           + self_propping_scale · R^n
           − gouge_fill(s)
```
clamped to `[min_hydraulic_aperture, max_hydraulic_aperture]`, with
`retention_factor = retention_residual + (1 − retention_residual)·R`.

Undocumented in both: the stress-aperture term, the retention factor, the self-propping
term, and the clamps (the theory manual mentions bounds in prose but not in the equation).
`self_propping_scale = 0` in all four decks, so that one is dormant and may fairly be
omitted from the manuscript — but it belongs in the manual.

**The substantive error.** Both docs claim the model contains no separate cumulative-dilation
term, because dilation is routed kinematically into $g_n$, and that adding one would
double-count. Paper §3.5.4: *"this is the reason it contains no dilation term of its own."*
Theory, "Remark: What not to do": *"Both are already in $\langle g_n\rangle_+$. Doing so
double-counts the physics."*

That is true for two specimens and false for the other two:

| specimen | `dilation_opens_joint` | `use_kinematic_aperture` | `dilation_scale` | `use_slip_damage` | double count? |
|---|---|---|---|---|---|
| SW-T1 | true | **true** | 0.0 | false | no |
| SW-T2 | true | **true** | 0.0 | false | no |
| SW-S3 | true | **false** | **0.038** | true | **yes** |
| SW-S4 | true | **false** | **0.0117** | true | **yes** |

On SW-S3 and SW-S4 the dilation enters the mechanical aperture kinematically *and* is fed
in again through the separate `dilation_scale` term. This is precisely the construction both
documents forbid.

It also explains a result already on record: on SW-S4 the correlation between hydraulic
aperture and mechanical opening is $r = 0.562$, against 1.000 / 0.999 / 0.946 on the other
three. The `dilation_scale` there was cut ~17× during fitting to hold $a_h$ at an earlier
calibration. The hydraulic aperture on that specimen is a fitted channel, not a consequence
of the mechanics — which is the honest reading of why flow and dilation decouple there.

The gouge term is likewise only active on the two saw cuts; both docs present it as general.

**Fix.** State the full six-term law in the manual. In the manuscript, either state the law
with a per-specimen table of which terms are active, or — better — say directly that the
tensile pair uses the single-source-of-truth kinematic construction and the saw cuts carry
an additional fitted dilation feed, and that this is a known asymmetry.

### A4. The stated reason for rejecting the Bakhtar aperture law is refuted by this repo's own measurement

**Affects:** paper §3.6, third paragraph; §6.6 limitation 9.

The manuscript says the closed form $a_h \propto a_m^2/\mathrm{JRC}^{2.5}$ has "no intrinsic
saturation", that transmissivity therefore scales as the cube of an unbounded square, and
that "this unbounded sensitivity is sharpest exactly where the aperture itself is changing
fastest… and in our implementation it destabilised the coupled Newton solve there."

`scripts/aperture_law_sensitivity.py` measured this on 2026-08-16 and found the opposite:

* the calibrated `mechanical_aperture_offset` is 30.79 µm and dominates every mechanical
  aperture SW-S4 ever reaches (peak 4.36 µm), so $(E+30.79)^2$ is near-linear there —
  measured $\mathrm{d}\ln T/\mathrm{d}\ln E$ tops out at **0.74**, not 6;
* the hydraulic aperture stays 0.74–0.95 µm against an 8 µm clamp, so the clamp never binds;
* `bb_jrc_mobilized` is pinned flat at 17.5 in every run, so JRC degradation never fires;
* transmissivity ratio Bakhtar/additive over the whole operating range is **1.00 to 1.45**.

Two laws within 45 % of each other everywhere the specimen goes cannot be the instability.
The destabilisation is real and reproduced cross-repo, but the mechanism is that the Bakhtar
deck **disables the additive law's entire negative-feedback stack** — the bounded power-law
closure, the dilation retention factor and the gouge reduction — not that the power law is
stiff.

**Fix.** Replace the stated mechanism. The current wording would not survive a referee who
asked for the sensitivity number, and the correct explanation is more interesting: it is a
statement about which feedbacks a coupled HM solve needs, not about a curve's slope.

### A5. The envelope-discriminability premise is contradicted by the 08-17 result

**Affects:** paper §3.5.2 (closing three paragraphs), §5.5, §6.3.

§3.5.2 asserts: *"Two parameterisations that agree at a single calibration point can
therefore disagree by 40 % in slope, which is what §5.5 measures,"* and the following
paragraph builds the discrimination argument that §5.5 and §6.3 are then wholly built on.

The 2026-08-17 analysis found that on this loading path cohesion and JRC are not separately
identifiable — the two envelopes' slopes differ by about **3 %**, not 40 %. The dataset does
not discriminate them.

The good news is that this is already resolved at the level of intent: discussion 1 was
reframed to a **performance** claim (BBFast scores better than MC against Table 2) rather
than a mechanism claim. But §3.5.2 still asserts the old premise in the formulation section,
and §5.5/§6.3 are still written as placeholders for the old comparison.

**Fix.** Retract the 40 % sentence. Rewrite §5.5 and §6.3 around the performance comparison
the 94-series will supply, and add the identifiability result as its own finding — "this
loading path cannot separate cohesion from JRC" is a genuine contribution about what the
benchmark can support, and it belongs next to the §6.1 argument, which makes exactly this
kind of point about the load-frame stiffness.

### A6. The theory manual's verification suite mostly does not exist

**Affects:** theory Part VIII in full; paper §4.4 and §5.1 lean on it.

Part VIII, "The test suite", describes eight verification tests in the present tense. What
is actually in `test/tests/`:

| described in Part VIII | implemented |
|---|---|
| Terzaghi 1D consolidation | ✅ `verification/terzaghi` |
| Mandel | ✅ `verification/mandel` |
| Normal closure, single element | ❌ |
| Coulomb return mapping | ❌ |
| Barton–Bandis envelope | ❌ |
| Cubic-law fracture flow | ❌ |
| Sneddon pressurised crack | ❌ |
| Inclined fracture, far-field compression | ❌ |

Six of eight are unimplemented. Conversely, five tests that **do** exist are undocumented:
`kernels/mass_storage`, `kernels/thermal_storage`, `kernels/simple_diffusion`,
`materials/bb_cohesion`, `materials/biot_modulus`, and `verification/pressure_diffusion`.

The two cross-model benchmarks are described as being run "with *all four* laws". There is
no such harness.

**Fix.** Split Part VIII into "implemented" and "specified but not yet implemented", and
document the five existing tests. This matters beyond tidiness: the manuscript's §4.4
enumerates a verification protocol and §5.1 reports verification results, and a code paper
that overstates its own test coverage is the single easiest thing for a referee to check.

### B3. §6.4 and limitation 8 describe a defect that was diagnosed and fixed

Both state, as a live open problem, that SW-S4's simulated shear stress "goes *negative*
while Table 2 stays small and positive" post-slip, and call it "a sign reversal, not a
magnitude error". §6.4 spends four sentences reasoning about what it might mean —
dissipation bound saturating, or missing rate-dependence in residual friction.

The cause was found on 2026-08-17: the plotted differential stress was being read in the
wrong stress frame, low by α·p — a skeleton-versus-total mismatch in the reporting channel,
not a constitutive failure. It was caught by a sibling-operator agreement test and corrected
in the 91-series. SW-S4 is now final at 6.05 % mean nRMSE.

Both passages need deleting. As written they advertise a model failure that is not real.

by the 89–93 refits. Its output currently prints "(deck has 23.35)" against decks that run
1.96. Any figure or number sourced from it is wrong. Either update its table or mark it
historical.

### B5. Editorial scaffolding still in the body

whole arguments parked in backticks, never merged into prose:

## Part C — Missing content

### C1. The three discussion sections do not exist yet

Per the current plan, the discussion needs: (1) BBFast outperforms Mohr–Coulomb, scored;
(2) permeability enhancement retained after the first cycle; (3) post-shut-in reactivation.
§6.3 is a placeholder written for the *old* mechanism framing of (1); there is nothing at
all for (2) or (3). The 94/97/98 runs will supply the data; the metrics for (2) and (3) are
defined in `Examples/YeGhasemmi2018/DISCUSSION_DECKS_97_98.md` §4.

### C2. The rate-and-state material is in neither document

`ADOrcaBartonBandisRateStateHardening` (`include/` + `src/InterfaceMaterial/`, added
2026-08-17 in commit `eee7e74`) is undocumented. Both its construction and its **negative**
result are worth reporting: the hypothesis that a rate-and-state $b$ term would heal the
hold-stage behaviour was tested and falsified, and $a-b<0$ stalls the solver. A falsified
mechanism, stated as such, is stronger than silence.

### C3. `tangential_viscosity` is documented as pure numerics, and it is not

Theory §"Regularisation" gives the correct rule — choose $\eta_t$ so that $\eta_t V \ll Y$ —
and the paper's Table at line 1190 lists it as a numerical residual term.

In the production decks that rule is violated. SW-S4 runs $\eta_t = 3.5\times10^{12}$,
**8.75× the other three**, and the resulting overstress is worth 0.31 MPa mean and 0.87 MPa
peak on that specimen — first-order on the ramps, relaxing to zero during holds. The
2026-08-18 experiment showed it functions as a hidden rate law worth 0.035–3.5 MPa.

A parameter that changes shear strength by up to 3.5 MPa is a constitutive choice, and
reporting it in the numerics table understates it. It should be reported per specimen with
its measured $\eta_t V$, alongside the note that the holds are where it relaxes — which is
also why the cyclic permeability probe is taken at holds.

### C4. Findings from 08-17/08-18 absent from the discussion

Each of these is a result, not a caveat, and the discussion is where they belong:

1. **Q is a stress readout, not an aperture one, on SW-S4** — $r(a_h, d_n) = 0.562$ there
   against 1.000 / 0.999 / 0.946. Corrects the natural assumption that Q tracks opening.
2. **SW-S4's cohesion channel is identically zero**, so `D_c`'s bracket splits — stage 4
   wants 58 µm, stage 11 wants 74 µm. The mechanism behind the specimen's one remaining
   defect.
3. **SW-S4 slips on ramps, not holds**, which is why lowering `D_c` worsens the staircase.
   The `D_c` bracket failed in both directions; 90_08 is final.
4. **The output-only reporting knobs were removed from SW-S3**, moving its score from
   3.59 % to 4.58 %. The worse number is the defensible one — it reports the raw kinematic
   jump on the same basis as the other three. Worth a sentence, because reporting a *worse*
   score after removing a fit is exactly the provenance argument §4.3 is making.
5. **Cross-machine reproducibility floor**: 0.08 pp on mean nRMSE. Sets the precision at
   which any ranking in §5 can be quoted.

### C5. Theory Part V is titled "The four constitutive laws"; there are more

Registered interface materials: `ADOrcaBartonBandisContactTractionFastAD(Hardening)`,
`ADOrcaBartonBandisFlowRSFContactTraction`, `ADOrcaBartonBandisRateStateHardening`,
`ADOrcaCohesionlessDamageMohrCoulombContactTraction`, `ADOrcaCohesionlessDamageRSFBBContactTraction`,
`ADOrcaDecoupledDilationRoughnessContactTraction(CompressionTensile)`,
`ADOrcaPeakShelfTailFlowRSFContactTraction` — plus three permeability materials
(`RoughnessDamage`, `Hysteretic`, `BartonBandisBakhtar`).

Part V documents four and does not say the inventory is a selection. The Bakhtar
permeability material, which §3.6 of the manuscript discusses at length, is absent from the
manual entirely.
